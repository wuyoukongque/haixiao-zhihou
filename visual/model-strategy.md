# 《海啸之后》AI 视觉模型策略

目标不是“能生成图片”，而是做出目前 AI 能达到的高水准视觉资产：

- 封面要有出版级审美
- 插画要风格统一
- 内页图要服务阅读节奏
- 网站和短视频可以复用同一视觉系统
- 生产流程要可批量、可复现、可迭代

## 结论

推荐采用“三层模型策略”：

1. **主生产模型：火山生图 API**
   - 用于批量生成章节插画、幕间图、网页配图。
   - 优点是你已有 API，适合自动化生产。

2. **高审美校准模型：Nano Banana Pro / Gemini 3 Pro Image**
   - 用于封面探索、复杂构图、图文结合、信息型视觉、风格母版。
   - 特别适合把书稿内容转成更准确的视觉隐喻。

3. **精修与复杂语义模型：OpenAI GPT Image**
   - 用于难图、局部重绘、复杂概念解释、风格稳定性检查。
   - 适合做少量关键图的高质量补强。

NotebookLM 不建议作为主视觉生产工具。它适合：

- 让模型理解整本书
- 生成内容概览
- 生成视频概览做灵感参考
- 帮我们发现章节之间的视觉线索

但它不适合承担最终资产生产，因为：

- 对单张图的构图控制不够细
- 对统一风格和批量资产管理不够稳定
- 输出更偏“概览视频”，不是出版级插画管线

## 模型分工

| 任务 | 首选 | 备选 |
|---|---|---|
| 封面概念探索 | Nano Banana Pro | GPT Image |
| 封面最终图 | Nano Banana Pro + 人工后期 | GPT Image |
| 章节插画批量生产 | 火山生图 API | Nano Banana Pro |
| 复杂哲学隐喻图 | Nano Banana Pro | GPT Image |
| 图中文字直接生成 | Nano Banana Pro / Ideogram | GPT Image |
| 内页纸张纹理、装饰图 | 火山生图 API | 本地后期合成 |
| 短视频视觉图卡 | 火山生图 API | NotebookLM 做灵感参考 |
| 视频概览/故事板 | NotebookLM | 手动分镜 |

## 最优工作流

### 第一阶段：视觉母版

用 Nano Banana Pro 或 GPT Image 生成 6-9 张方向图：

- 退潮封面
- 文明地层封面
- 碳与硅封面
- 第一幕主视觉
- 第二幕主视觉
- 第三幕主视觉
- 一张章节扉页样张
- 一张关键句页样张
- 一张听书模式背景图

目标不是马上定稿，而是找到“这本书应该长什么样”。

### 第二阶段：风格锁定

从母版中选 1-2 张作为风格参考，提炼：

- 线条粗细
- 纸张底色
- 色彩比例
- 构图留白
- 人物是否出现
- AI 元素的显性程度
- 插画与文字的距离感

### 第三阶段：批量生产

用火山 API 按统一提示词生成：

- 每章 3 张候选主插画
- 每幕 2 张候选幕间图
- 每章 2-3 张短视频图卡背景

每张图都记录：

- 章节
- 提示词
- 模型
- 参数
- 选用/弃用原因

### 第四阶段：后期统一

所有最终图进入统一后期：

- 加纸张纹理
- 降饱和
- 统一暗部为墨黑/深海蓝
- 统一高光为象牙白
- 轻微颗粒和版画感
- 裁切成电子书、网站、短视频三套比例

### 第五阶段：页面验证

图片不能单独看，必须放进页面里看：

- 封面缩略图是否成立
- 内页插画是否抢正文
- 翻页时图文节奏是否舒服
- 听书模式是否安静
- 手机屏幕上是否仍然高级

## 推荐判断标准

一张图是否进入最终资产库，不看“好不好看”一个指标，而看：

1. 是否符合《海啸之后》的思想气质
2. 是否避免了廉价 AI 科技感
3. 是否能和其他章节统一
4. 是否有纸质书插图的耐看性
5. 是否有足够留白承载文字
6. 是否能在电子书、网站、短视频中复用

## 关于“最高水平”

最高水平不是单一模型决定的，而是下面几件事叠加：

- 顶级模型出母版
- 批量模型出候选
- 明确统一的艺术指导
- 严格筛选
- 后期统一
- 放进真实阅读界面反复验证

对这本书来说，最好的路线不是“每张图都让最贵模型生成”，而是：

**用最强模型定义审美，用可控 API 批量生产，用人工和后期把它们统一成一本书。**
