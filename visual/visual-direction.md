# 《海啸之后》视觉设计方向 v1

## 视觉总命题

这本电子书不应像一个普通网页，也不应像一个科技产品说明书。

它应该像一本被放进未来阅读器里的纸质思想书：

- 有纸张的温度
- 有历史书的纵深
- 有哲学书的留白
- 有艺术图录的插画节奏
- 有轻微但明确的 AI 时代感

核心视觉气质：

**克制、辽阔、历史感、哲学感、纸张感、轻微未来感。**

## 视觉隐喻

主隐喻：

- 海啸前的退潮
- 工作与身份的断裂
- 文明地层
- 碳基生命与硅基智能
- 人类作为过渡物种
- 纸张、手稿、档案、博物馆图谱

避免：

- 俗套机器人
- 霓虹赛博城市
- 蓝紫色科技光效
- 过于商业海报化的 AI 视觉
- 密密麻麻的信息图堆叠

## 插画统一风格

推荐风格名：

**纸上文明寓言插画**

风格定义：

- 旧百科全书蚀刻线条
- 淡水彩或矿物颜料上色
- 纸张纹理可见
- 构图有博物馆图录感
- 主题带寓言性，不做直白说明图
- 少量硅基蓝绿色细线作为 AI 的存在感

常用画面元素：

- 海、退潮、裸露沙地、搁浅的鱼
- 工厂、织布机、打字机、办公桌、工牌
- 教室、黑板、空椅子、旧试卷
- 面具、镜子、家庭餐桌、空房间
- 巨型组织、城市剖面、数据河流
- 神经、芯片、树根、星图、化石、船

## 色彩系统

基础色：

- 纸张象牙白：`#F4EBDD`
- 墨黑：`#1F1B16`
- 石墨灰：`#59544C`
- 深海蓝：`#18364A`
- 铁锈红：`#9A4E35`
- 暗金：`#B08A45`

AI 点缀色：

- 硅基青：`#4FA6A3`
- 冷光蓝：`#7FB7C7`

原则：

- 纸张色和墨色是主角。
- 深海蓝、铁锈红、暗金用于章节和插画重心。
- 硅基青只作为线索，不喧宾夺主。

## 字体方向

正文：

- 思源宋体 / Noto Serif CJK SC
- 或屏幕优化宋体

标题：

- 更有碑刻感、书籍感的宋体或衬线字体
- 标题字号大，但不压迫

界面 UI：

- 可使用现代无衬线字体
- 播放器、目录、页码保持轻，不抢正文

## 页面节奏

每章建议包含：

1. 章节扉页
2. 正文阅读页
3. 关键句留白页
4. 插画跨页或半页
5. 引用/历史材料页
6. 章节结尾余韵页

排版原则：

- 每页只承载一个清晰思想单元。
- 大段正文不要超过页面的 60%-70% 高度。
- 关键句可以单独占半页甚至整页。
- 插画不必每页都有，但出现时要有重量。
- 幕间页要像换卷，视觉气息明显改变。

## 封面方向

### 方向 A：退潮

画面：

海水异常退去，沙滩裸露，远处海平线安静得不自然。前景可以有搁浅的鱼、半埋的工牌、旧键盘或纸页。

含义：

人们以为是低潮，其实海啸正在形成。

### 方向 B：文明地层

画面：

像地质剖面一样，从下到上依次出现石器、农具、齿轮、打字机、电脑主板、神经网络纹理。

含义：

AI 不是一个工具更新，而是文明地层的换代。

### 方向 C：碳与硅

画面：

人体神经、树根、芯片线路、星图和化石交织成一个博物馆标本式构图。

含义：

人类与 AI 的关系不是战争，而是交接和融合。

## 章节题名系统

章节页采用三层标题：

1. 幕名：文明阶段
2. 章名：核心命题
3. 副标题：一句哲学判断

示例：

```text
第一幕
冲撞

第一章
和工作说再见

当一个社会用职业回答“我是谁”，
工作消失就不只是经济问题。
```

## 生图工作流

推荐主流程：

1. 先生成 3 张封面方向样图。
2. 选定一种视觉母体。
3. 用同一风格提示词批量生成章节插画。
4. 每章只保留 1 张主插画和 2-3 张候选局部图。
5. 对最终图做统一后期：
   - 加纸张纹理
   - 降低饱和度
   - 统一暗部颜色
   - 加轻微版画颗粒
6. 接入电子书页面。

## 模型使用建议

主生产：

- 火山生图 API
- 原因：你已经有 API，适合批量化、自动化、低摩擦生产。

备选/校准：

- OpenAI `gpt-image-1`：适合复杂语义、封面概念、需要精准遵守提示词的图。
- Google Imagen 4：适合高质量图像、文字渲染和多风格产出。
- Ideogram：适合需要把标题文字直接放进画面里的封面探索。
- Midjourney：适合审美探索和风格找样，但自动化集成相对不如 API 生产直接。

建议不要一开始多模型混用。先用火山 API 批量出风格，再用一个备选模型做封面或疑难图校准。
