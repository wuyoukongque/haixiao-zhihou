## 核心定位

《海啸之后》不是一本单纯预测 AI 的书，而是一套关于 AI 之后人类社会如何重组的推演。

核心论点：

人类历史上第一次，我们可能同时拥有“不需要工作”和“物质足够丰盛”。这不是简单的技术进步，而是工作、身份、组织、爱情、教育、认知和文明交接方式的整体改写。

核心比喻：

- 互联网像浪潮，改变信息流动，大多数人最终适应了。
- AI 像海啸，冲掉现代社会更深的地基：工作和身份的关系。

## 制作原则

### 有声书

- 保留原书的宏观推演和设问驱动。
- 转为更适合听觉的节奏：短句、清晰转场、一个段落一个任务。
- 不把书稿读成论文，也不做成夸张演讲。
- 口吻应像一个清醒、克制、持续追问的讲述者。

### 网站版

- 网站可以先做成章节阅读与音频播放结合的电子书。
- 每章保留摘要、关键问题、章节音频、正文阅读和可分享摘录。
- 后续可增加短视频切条入口、主题索引和引用来源页。

### 短视频

- 每条短视频只讲一个问题、一个锋利观点、一个结论。
- 从章节中抽取高密度片段，不机械照搬整章。
- 视觉上以标题卡、关键句卡、结构卡、引用卡为主，避免喧宾夺主。
